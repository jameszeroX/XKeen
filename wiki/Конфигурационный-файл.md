## Конфигурационный файл xkeen.json

При чистой установке XKeen создаётся пустой файл настроек по пути `/opt/etc/xkeen/xkeen.json`. При необходимости можете заполнить его по примеру ниже, соблюдая синтаксис JSON. Также можете создать этот файл заранее — до установки XKeen. В этом случае указанные в нём настройки (например, токен доступа, параметры повторных загрузок или пользовательский прокси) будут применены уже на этапе установки.

```
{
  "xkeen": {
    "rci_token": "",
    "gh_proxy": "",
    "retries_download": "",
    "retry_delay_download": "",
    "verify_downloads": "",
    "policy": [
      {
        "name": "xkeen0",
        "port": ""
      },
      {
        "name": "xkeen1",
        "port": "80,443,596:599,1400,3478,5222"
      },
      {
        "name": "xkeen2",
        "port": "!7777,8888:9999"
      }
    ],
    "xray": {
      "geofile_update": true,
      "geodata": [
        {
          "file": "geosite_name.dat",
          "url": "https://site.com/geosite.dat"
        },
        {
          "file": "geoip_name.dat",
          "url": "https://site.com/geoip.dat"
        }
      ],
      "speed_balancer": {
        "enabled": false
      }
    },
    "mihomo": {
      "gomemlimit_percent": "",
      "gomemlimit_mb": ""
    }
  }
}
```

- `rci_token` - токен доступа к RCI, создаётся в веб-интерфейсе и требуется для KeeneticOS 5.2
- `gh_proxy` - пользовательский прокси для загрузок с GitHub (пример `"gh_proxy": "https://ghproxy.me",`)
- `retries_download` - количество повторных попыток загрузки с GitHub (пример `"retries_download": "3",`)
- `retry_delay_download` - количество секунд между попытками повторных загрузок (пример `"retry_delay_download": "10",`)
- `verify_downloads` - проверка контрольной суммы загруженных файлов (возможные значения `strict|warn|off`, по умолчанию `warn`)
- `policy` - раздел, описывающий пользовательские политики маршрутизации
- `xkeen0` - пользовательская политика, проксирование на всех портах (имя политики произвольное)
- `xkeen1` - пользовательская политика, проксирование на перечисленных портах (имя политики произвольное)
- `xkeen2` - пользовательская политика, проксирование на всех портах, кроме перечисленных (имя политики произвольное)
- `geofile_update` - требуется ли обновлять геофайлы Xray средствами XKeen (по умолчанию `true`)
- `geodata` - раздел, описывающий пользовательские геофайлы Xray, которые нужно обновлять средствами XKeen
- `file` - имя геофайла в директории `/opt/etc/xray/dat/`
- `url` - ссылка для загрузки геофайла
- `speed_balancer` - балансировщик xray по фактической скорости серверов ([подробнее](https://github.com/jameszeroX/XKeen/wiki/Configuration#балансировка-по-фактической-скорости))
- `gomemlimit_percent` - память, выделяемая процессу mihomo в процентах (при пустом значении 50% от RAM устройства)
- `gomemlimit_mb` - память, выделяемая процессу mihomo в MB (если задано, имеет приоритет над предыдущим пунктом)
